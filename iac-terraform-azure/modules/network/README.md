## 📡 Network Module

This module deploys a Virtual Network in Azure.

### Inputs

| Name                | Type        | Description         | Default         |
|---------------------|-------------|---------------------|-----------------|
| vnet_name           | string      | VNet name           | n/a             |
| address_space       | list(string)| CIDR block(s)       | n/a             |
| location            | string      | Azure region        | n/a             |
| resource_group_name | string      | Resource group name | n/a             |

### Outputs

_Not defined in this version_
