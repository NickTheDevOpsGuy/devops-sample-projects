# 🌐 Terraform Azure Lab

This project sets up a basic Infrastructure as Code (IaC) Terraform environment for Azure.

## 🧪 Project Overview
This project:

* Provisions Azure infrastructure using Terraform (modular setup)
* Supports remote backend storage for state
* Uses CI (linting, format check, security scan)
* Is workspace-ready and DevOps polished

## 📦 Structure

```
terraform-azure-lab/
├── infrastructure/         # Main Terraform files
├── modules/                # Modularized Terraform components
├── env/                    # Environment variable templates
├── scripts/                # Setup and utility scripts
├── .github/workflows/      # GitHub Actions CI
├── .gitignore              # Git ignored files
└── README.md               # This file
```

## 🚀 How to Use This Project (Step-by-Step)

✅ 1. Pre-reqs
Make sure you have:

```bash
# CLI tools
az login             # Azure CLI
terraform -v         # Terraform v1.x+
tflint --version     # (optional) for linting
tfsec --version      # (optional) for security
pre-commit --version # (optional) for local checks

```

##🧱 2. Set Up Remote Backend (Optional)
Use this if you want remote state in Azure:

```bash
cd scripts/
chmod +x backend-setup.sh
./backend-setup.sh
```

It creates:

* Resource group tfstate-rg
* Storage account tfstateaccount
* Container tfstat
* Make sure backend.tf matches those names.

🔐 3. Configure Environment
Create your local .env file:

```bash
cp env/.env.example .env
```

## 🧪 4. Initialize and Deploy Infra

```bash
cd infrastructure/
terraform init
terraform workspace new dev   # Optional: multi-env
terraform plan
terraform apply -auto-approve

```

## 🧹 5. Clean Up

```bash
./scripts/cleanup.sh
```

## 🛡️ CI/CD Features (GitHub Actions)
On PR:

* terraform fmt -check
* terraform validate
* tflint
  * tfsec

You can run these manually too:

```bash
tflint
tfsec .
```

## 🔄 Docs & Diagrams
* Each module has a README.md generated by terraform-docs
* Architecture diagram stubs are in docs/

You can update docs like this:

```bash
make docs
```
