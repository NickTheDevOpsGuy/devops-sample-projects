# 🌍 Terraform Azure Lab

This project deploys modularized Azure infrastructure using Terraform, including:

- Azure Virtual Network (VNet)
- Azure Kubernetes Service (AKS)
- Azure Storage Account

It includes GitHub Actions CI/CD, pre-commit hooks, and remote backend support.

## 🚀 Getting Started

```bash
git clone https://github.com/NickTheDevOpsGuy/devops-sample-projects.git
cd terraform-azure-lab
chmod +x scripts/setup.sh
./scripts/setup.sh dev
```
